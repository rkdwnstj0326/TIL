### 2-1. 3트에서 나온 문장

```python
    for i in range(len(scores[0])):
    # 이렇게 해야지 scores[0]의 학생 점수가 인덱스화 돼서 반복됨.
    # scores[0]을 먼저 본 이유 : 과목수가 몇개인지 알아내려고임. 계산을 첫번째 학생부터 하겠다가 아님!
```

**"계산을 첫번째 학생부터 하겠다가 아님!"**

이게 이 문제의 핵심 오개념 교정입니다. `scores[0]` 을 보면 "0번 학생"이 떠오르는데, 여기서는 **"한 줄에 값이 몇 개인지 재는 자"** 로 쓰이거든요. 해설에도 이렇게 적혀 있습니다.

> `len(scores)` = 줄이 몇 개인가 = 학생 수
> `len(scores[0])` = 한 줄에 값이 몇 개인가 = 과목 수

준서 님은 이걸 **해설을 보기 전에** 본인 문장으로 쓰셨습니다.



### 2-2. 그리고 그림까지 그리셨습니다

```
# 바깥 for
# "무슨 과목 계산할래?"
#         ↓
#         i = 0
#
# 안쪽 for
# "그 과목 점수를 학생들에게서 전부 가져올게"
#         ↓
# 학생1
# 학생2
```

**바깥 반복문이 "무엇을 정하는가", 안쪽 반복문이 "무엇을 모으는가"를 말로 분리하셨습니다.** 이번 주 과제 전체의 주제가 이 한 장면에 들어 있습니다.



### 2-3. 그리고 코드가 표준 답안보다 낫습니다

```python
def get_subject_totals(scores):
    result = []
    for i in range(len(scores[0])):
        total = 0
        for score in scores:          # <- 학생 리스트를 '값'으로 꺼냄
            total = total + score[i]  # <- 그 줄의 i번째 값
        result.append(total)
    return result
```

해설의 답안은 안쪽도 인덱스로 돕니다(`for r in range(len(scores))` => `scores[r][c]`). 준서 님은 안쪽을 **값으로** 도셨고요.

**이 방식은 이 문제의 가장 흔한 함정을 구조적으로 피합니다.** 해설의 오답 패턴 (2)번이 `scores[c][r]` 로 대괄호를 뒤집는 건데, 준서 님 코드에는 대괄호가 **하나뿐**이라 뒤집을 수가 없거든요.

> **역질문 1.**
> 준서 님 코드에서 `score[i]` 의 `score` 에는 무엇이 담기나요? 그리고 `i` 는 무엇의 번호인가요?
> 둘을 한 문장으로 이어서 *"`score[i]` 는 ___의 ___번째 점수"* 를 완성해 보세요.



#### 다만 변수명 하나는 짚을게 있습니다

`score` 라는 이름에 **한 학생의 점수 리스트 전체**가 담깁니다. 이름은 "점수 하나"를 뜻하는데요.

01번에서는 정확히 구분하셨습니다. `stu_score`(한 학생의 점수 리스트) / `score`(과목 하나의 점수). 02번에서만 `score` 에 리스트가 들어갔어요.

`for student in scores:` => `total = total + student[i]` 로 쓰면 **"학생의 i번째 점수"** 로 읽힙니다.

### 3-4. 도움받은 코드를 안 쓰신 것

```
# 여기서 막혔습ㄴ디ㅏ. 제가 생각했던 방식이 있었는데 구현하지 못해서, 원석님이 enumerate사용을 도와주셧으요
```

그리고 그 `enumerate` 버전을 통째로 주석 처리하신 뒤 이렇게 쓰셨습니다.

```

# 조건문?반복문으로 작으면 넘기고 큰거면 그 값을 기준인덱스에 넣어서 비교할게 없을 때 까지 돌리는 방법? 을 생각햇습니다
```

**받은 코드를 쓰면 5분이면 끝났을 텐데, 자기 방식으로 다시 짜셨습니다.** 그리고 그게 네 번의 실패로 이어졌고, 그 네 번이 3-1의 기록이 됐습니다.

이건 좋은 선택이었습니다. `enumerate` 를 쓰면 "값과 인덱스가 같이 나온다"는 편의만 얻고, **"기준값이 갱신된다"는 개념은 못 얻습니다.** 준서 님이 8시간에 얻으신 건 그 개념이에요.

다만 한 가지만. **`enumerate` 버전도 정답입니다.** 두 방식의 차이는 이렇습니다.

```python
# 직접 인덱스를 도는 방식 (준서 님 최종)
for stu_index in range(1, len(stu_max)):
    if max_student_score < stu_max[stu_index]:

# enumerate 방식
for index, stu in enumerate(stu_max):
    if stu > max_student_score:
```

`enumerate` 는 **인덱스와 값을 한 번에 꺼내주는** 함수라 `stu_max[stu_index]` 를 매번 쓸 필요가 없어집니다. 다만 0번부터 도니까 첫 회차에 자기 자신과 비교하게 되고요(결과에는 영향 없습니다).

**둘 다 알아 두시고, 지금은 직접 인덱스 방식을 유지하세요.** 인덱스가 어떻게 움직이는지가 눈에 보이는 쪽이 지금 준서 님께는 더 낫습니다.

## 5. 문제별 상세 피드백

### 문제 01 — `get_student_totals`

```python
def get_student_totals(scores):
    result = []
    for stu_score in scores:
        total = 0
        for score in stu_score:
            total = total + score
        result.append(total)
```

**해설의 답안과 구조가 같습니다.** `total = 0` 이 바깥 `for` 안에 있고, `append` 가 안쪽 `for` 뒤에 있습니다. 이 문제의 두 핵심을 다 잡으셨어요.

- 2트: 그릇은 있는데 `result` 에 넣는 동작(`append`)이 없음

그리고 2트 결과를 *"[] 빈 리스트만 반환됨"* 이라고 적어 두셨습니다. **실행해서 확인하셨다는 뜻입니다.**

```
#    -> 새로운 학생이 시작될 때 마다 총점을 0으로 리셋해야해서 첫번째 반복문 안에 써야됨
```

```python
def find_positions(shelf, target):
```

```python
# 2트: for i_shelf in range(len(shelf[0])):  # 바깥이 칸 수만큼 돔
```

**세 개가 전부 다른 오개념입니다.** 그리고 회고에 정확히 정리하셨어요.

### 문제 04 — `count_steps_to_one`

```python
def count_steps_to_one(n):
    count = 0
    while n != 1:
        if n % 2 == 0:
            n = n // 2
            count = count + 1
        else :
            n = (n * 3) + 1
            count = count + 1
    return count
```

**`while` 을 처음 쓰셨는데 40분에 끝내셨습니다.** 그리고 `[1]` 추가 질문 답이 정확합니다.

```
# 답 : 알수없음. 규칙을 적용하면서 확인해야댐
# 답 : n=1이 되었으 때 멈춰야함. 그 전에 멈추면 안댐
```

**"반복 횟수를 미리 알 수 없다"와 "언제 멈춰야 하는가"** — `while` 이 필요한 이유와 `while` 의 조건식을 둘 다 짚으셨습니다.



#### 1트에서 `return` 문제를 또 만나셨습니다

```python
# #1트
#     while n != 1:
#         if n % 2 == 0:
#             return n // 2        # <- 계산하고 바로 끝내버림
```

그리고 이렇게 쓰셨죠.

```
# return을 이렇게 쓰면 안된다는 지피티. 바로 끝나버리는걸 또 생각을 못했음
```

**"또"** — 준서 님이 세 주 동안 네 번 만난 실수입니다. (1주차 04번, 05번 / 2주차 04번 / 이번 04번)

다만 이번엔 **1트에서 2트로 바로 넘어가셨습니다.** 1주차에는 4트까지 갔었죠. 그리고 회고에도 정확히 적으셨습니다.

```
# return을 반복문 안에 써서 한 번 계산하고 함수가 끝나는 구조로 작성햇듬
```

**한 문장으로 굳혀두세요.**

> **`return` 은 "답을 내놓는다"가 아니라 "여기서 그만한다"이다.**


준서 님이 1트에서 이렇게 쓰셨죠.

```python
#         elif n % 3 == 0:      # <- 홀수 판정을 "3으로 나눠떨어지면"으로
#         else:
#             return 0
```

**세 갈래로 나누셨던 겁니다.** 그런데 실제로는 두 갈래(짝수 / 홀수)뿐이라 `else` 하나면 충분하죠. 아마 그 이야기를 쓰시려던 것 같은데, 문장이 *"이렇게 쓸 이유가 없음"* 으로 되어 있어서 `else` 자체가 불필요하다는 뜻으로 읽힙니다.

```python
        else :  # n % 2 == 0 이 거짓이면 무조건 홀수다. 조건을 다시 쓸 필요가 없다.
```



#### `count = count + 1` 이 두 번 나옵니다

```python
        if n % 2 == 0:
            n = n // 2
```

#### `[3] (1)`, `(2)` 핵심 질문도 비어 있습니다

특히 (2)번은 이 문제에서 답할 가치가 큽니다.

> 최고 총점 변수의 시작값을 0으로 두어도 이 문제에서는 안전합니다.
> 지문의 어느 조건 문장 때문에 안전한가요?

**답은 이렇습니다.** 이 문제에는 점수의 범위 조건이 따로 없지만, 성적표라서 음수가 없습니다. 그래서 `0` 으로 시작해도 갱신이 일어나죠.

하지만 준서 님은 `stu_max[0]` 으로 쓰셨습니다. **더 안전한 선택입니다.** 데이터에 음수가 섞여도 안 깨지거든요. (2주차 05번에서 순이익이 음수였던 것과 같은 상황입니다)

**"왜 안전한가"를 쓸 수 있으면 그게 이해한 겁니다.**

## 6. 이 과제의 핵심

> **1. 세 주 만에 표와 코드가 맞아떨어졌습니다.**
> 다섯 문제 전부 손 추적표가 코드와 일치합니다. 그리고 그게 다섯 문제 전부 정답으로 이어졌습니다. 표를 그리는 게 준서 님의 강점이라는 게 확인됐어요.
>
> **2. 탐색 골격의 기준값은 고정이 아니라 갱신되는 값이다.**
> `stu_max[0]` 과 계속 비교하면 `[6, 15, 10]` 에서 틀립니다. `max_student_score` 와 비교해야 합니다. 05번 8시간이 이 한 줄에 쓰였습니다.
>
> **3. 막히면 지난 주차 폴더를 먼저 여세요.**
> 05번의 그 코드를 2주차 04번에서 이미 쓰셨습니다. 30분 규칙을 "질문한다"가 아니라 **"전에 본 적 있는지 찾는다"** 로 먼저 쓰시면 됩니다.
