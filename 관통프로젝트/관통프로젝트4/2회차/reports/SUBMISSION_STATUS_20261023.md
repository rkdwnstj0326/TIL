# FinVOC 제출 문서 전환 상태 · 2026-10-23

제출 문서 세트를 FinVOC로 전환했다. README·요구사항 정의/대조·RAG 설계·테스트/화면·출처/조건·
시연·포트폴리오·체크리스트 상태와 보조 양식을 작성했다. ZIP도 FinVOC 주제의 정해진 이름으로 별도 생성한다.
기존 제출 준비 ZIP은 보존한다. 최신 패키지의 실제 경로·해시·검사 결과는 ZIP 옆 `package_audit.json`이 기준이다.

**문서 전환 완료와 과제 필수 기능 완료는 다르다.**
현재 회사분기37개 항목으로 약100개 조건 미충족, 필수 벡터 RAG·생성·대화/자연어 조건 기능 미완료,
알려진 UI/검색 결함 미수정, 공식 셀프·상호 점검 실제 결과 미반영이다.
이를 통과로 적거나 다른 프로젝트의 결과로 채우지 않았다.

과제 원본 PDF7~19,21~23쪽의 요구사항을 docs/requirements_traceability.md와 docs/submission_audit.md에 대조했다.
지정 형식: AI_코어프로젝트2_FinVOC금융민원분석AI_서울_1반_강준서.zip.
최신 제출처는 https://abit.ly/0i3bjzz 의 2회차 폴더이며, 파일명·제출 위치는 선생님의 최신 안내를 우선한다.
문서 형식은 Markdown으로 정리했다. PDF는 README/Word/PowerPoint 활용을 허용하므로 별도 Word/PPT를 필수로 만들지 않았다.
가상환경을 제외해 압축한다. 실제 업로드·최종 제출은 수행하지 않았다.
