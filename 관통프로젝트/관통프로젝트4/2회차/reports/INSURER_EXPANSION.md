협회의 [공식 HWP 작성 매뉴얼](https://consumer.knia.or.kr/common/filedown.do?fileName=minwon)을
전체 본문 추출해 공시대상·제외조건·분류를 확인했습니다(제정 2024-06-30).
중복·반복, 자율조정 성립, 합의취하, 임의철회, B2B, 소송관련 제외조건이 있습니다.
자체민원 이후 같은 내용으로 접수된 대외민원은 중복 제외를 인정하지 않는 예외도 있습니다.
문서의 매크로·스크립트는 실행하지 않았습니다.

**분모 확인의 한계:** 협회 HTML 및 매뉴얼에 상품표의 상세 분모(상품별/전체)가 명시되지 않았습니다.
새 15개 손해보험사는 상품 환산건수를 원문 그대로 보존하되 `denominator_scope`를 **미확인**으로
저장하고 화면에 주의사항을 표시합니다. 기존 두 회사와 교보생명은 직접 공시의 상품별 분모 문구를
유지합니다. 원시 보유계약 수는 모두 미확보이며 반올림된 환산값에서 역산하지 않습니다.
‘기타’ 상품의 빈 환산값은 0이 아닙니다. 상세 분모가 불명확한 상품간 환산값 비교는 보류합니다.
이 경우 비교 차트를 차단하고 원문 값만 표에 남깁니다. 분모가 확인된 회사의 차트는 유지합니다.

회사별 상품 구성이 달라 동일 단위만으로 피해율·서비스 품질 순위를 정하지 않습니다.
모든 세부 제외조건이 완전히 같다고 확정하지 않았습니다. 교보생명에는 금감원 즉시연금 전용코너
접수 건 제외, 예별손해보험에는 MG손해보험 이관 계약 공시라는 별도 주의사항이 있습니다.

## 검증 결과

- 기존 보험사 관측값 65개를 수정하지 않고 418개 추가: **483개**.
- 권역 28개를 포함한 화면 관측값 **511개**. 익명 사례 70개는 그대로 유지.
- 확장 검사 **204개 통과**: 회사·분기별 부분합/축간 합계, 관측키 유일성, 건수 타입,
  직접 공시 대조 52개, 매뉴얼 검토, 기존 데이터 보존 검사 포함.
- 기존 43개와 확장 204개를 함께 표시한 화면 검사 건수: **247/247**.
- 신규 채택 출처 3개 SHA-256 확인 및 캐시 재조회: 3회 적중, **HTTP 재호출 0회**.
- 자동 테스트 **30개 통과**, 실제 브라우저의 회사 선택·업권 전환·출처·분모 미확인 비교 차트 차단을 확인했습니다.
- 자동 시험과 브라우저 확인 기록은 `insurer_ui_validation.json`, `pytest-insurers.xml` 참조.
- 첫 pytest 실행은 샌드박스 임시 폴더 쓰기 권한 때문에 기존 합성 HTML 시험 1개가 실패했습니다.
  프로세스 TMP/TEMP만 프로젝트 runtime/test_temp로 지정해 재실행했습니다. 운영체제 영구 설정은 변경하지 않았습니다.

원래 `phase0_audit.json`, `insurer_stats.json`, `sector_stats.json`, `cases.json`은 덮어쓰지 않았습니다.
원래 보고서는 확장 이전 스냅샷입니다. 현재 확장 결과는 `insurer_expansion.json`이 기준입니다.

## 보류·접근 및 이용 범위

NH농협생명 최신 실제 페이지는 2026Q3와 Q2입니다. 검색 요약의 과거 Q2 표를 복사하지 않고
이번 Q2/Q1 확장에서 보류했습니다. KB 직접 페이지는 보안세션 오류 HTML이므로 수치 출처로
채택하지 않았으며, 협회가 별도로 공개한 통합 표에서 KB 관측값을 확보했습니다.

협회 robots 경로는 JPEG 오류 이미지로 이동해 유효한 정책 텍스트가 없었습니다.
정상 공개 통합 HTML과 연결된 매뉴얼을 정직한 User-Agent로 저속 수집하고 캐시했습니다.
유효한 허용 정책이 있었다거나 원문 재배포가 허용되었다고 주장하지 않습니다.
접근 차단이나 TLS 오류를 우회하지 않았습니다. 원문/가공 데이터는 로컬 교육·연구 범위로 보관하고
Git과 소스 ZIP에서 제외합니다. 모든 출처의 외부 재배포 이용 조건을 확인한 상태는 아닙니다.

익명 공개 사례를 신규 보험사의 사건으로 연결하지 않습니다. 이번 작업은 통계·출처 확장이며
의미 검색, 실제 GMS RAG 생성, 독립 30문항 평가는 여전히 후속 단계입니다.
