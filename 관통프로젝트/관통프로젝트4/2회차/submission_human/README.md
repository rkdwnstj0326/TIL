# FinVOC Korea — 실제 셀프·상호 점검 결과 보관

제출자: 서울 1반 강준서. 안내 작성일: 2026-10-23.

**공식 셀프 체크리스트와 실제 상호 점검 결과를 아직 제공받지 않아 반영하지 않았다.**
이 폴더의 `*_template.md`는 작성 보조용 빈 양식이다. 교육의 공식 양식이나 실제 평가 결과가 아니다.

1. 교육에서 제공한 공식 셀프 체크리스트에 FinVOC의 실제 실행 결과를 작성한다.
2. 옆 교육생에게 받은 점검과 내가 보낸 점검 결과를 각각 실제 날짜·대상 버전과 함께 보관한다.
3. 파일명만 추가해도 평가 통과로 바뀌지 않는다. 실제 내용을 확인한 후 `docs/checklists.md`와 `docs/submission_audit.md`를 갱신한다.
4. 패키지 검사를 다시 실행해 새 ZIP을 만든다. 기존 ZIP은 자동 갱신되지 않는다.

권장 보관명은 `official_self_check` / `peer_received` / `peer_sent`에 받은 원래 확장자를 붙인 것이다.
불필요한 연락처·계정·키를 문서에 넣지 않는다. 평가자 이름·점수·통과 여부를 미리 만들지 않는다.
