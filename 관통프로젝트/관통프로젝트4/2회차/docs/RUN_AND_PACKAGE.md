# FinVOC Korea — 실행과 제출용 압축

코드의 기준 위치는 바탕화면 `ai_core_pjt/2회차`다. 중간 제출준비 폴더를 거치지 않는다.

1. `FinVOC 실행.cmd` 더블클릭 → 브라우저가 열린다. 기본 주소는 http://127.0.0.1:8540/.
2. 종료할 때 `FinVOC 종료.cmd` 더블클릭. 브라우저만 닫으면 서버는 계속 실행된다.
3. 제출 직전에 `제출용 압축.cmd` 더블클릭.
4. `dist`에 생성된 `AI_코어프로젝트2_FinVOC금융민원분석AI_서울_1반_강준서.zip`을 확인한다.
5. 선생님 링크의 **2회차** 폴더에 사용자가 업로드한다. 현재 자동 업로드하지 않는다.

탐색기에서 폴더 전체를 바로 압축하면 숨겨진 .env와 큰 가상환경까지 들어갈 수 있다.
따라서 전용 압축 스크립트가 코드·문서·검증 결과만 선택하고 실제 .env·키·연락처·가상환경·DB·모델 캐시를 제외한다.
원문/가공 데이터의 외부 재배포 허용이 확인되지 않아 본문 데이터도 제외한다. 다른 컴퓨터는 README의 자료 준비 절차가 필요하다.

스크립트는 ZIP 무결성(CRC), 파일 해시, 문서 링크, 가상환경/비밀 파일 제외 여부를 검사한다.
이미 ZIP이 있으면 기존 파일을 runtime 안에 보관한 다음 최신 ZIP을 만든다. 최종 평가를 했다는 뜻은 아니다.
