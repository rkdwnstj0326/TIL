# FinVOC Korea — 요구사항 정의서

2026-10-23 · 서울 1반 강준서. 실제 구현·검사 기준.

공식 공시와 익명 업계 사례를 분리해 금융소비자보호 담당자의 검토를 지원한다. 개별 사건의 지급/법률 결과를 확정하지 않는다.

|번호|요구사항|상태|실제 범위|
|---|---|---|---|
|F2001|항목 메타데이터 적재|구현·수량 검증|실제 회사·분기 177개. 2024Q1~2026Q2. 같은 민원의 분류축을 별도 항목으로 세지 않음.|
|F2002|메타데이터 의미 색인|구현·로컬 검증|실제 다국어 MiniLM과 Chroma metadata 컬렉션.|
|F2003|검색어 추출 프롬프트|구현·실제 호출|한국어 검색어 JSON, 타입·범위 검사.|
|F2004|질문 시점 문서 수집·선별|구현·검색 범위 제한|기존 공식 목록 70개에서 검색·GMS 선별 후 원문 fetch. 웹 전체 최신 검색은 아님. 선택 공시 우선 수집.|
|F2005|외부 문서 별도 색인|구현·로컬 검증|선별한 본문만 질문 시점에 별도 컬렉션에 색인.|
|F2006|근거 검색·병합|구현·로컬 검증|선택 메타데이터 상시 포함, item_id 필터, 실제 의미 검색/MMR.|
|F2007|근거 답변 생성|구현·대표 질문 실검증|LangGraph retrieve/generate 두 노드와 실제 GMS. 모델 기간 혼동을 발견해 검사로 보류.|
|F2008|인용과 출처|구현·구조 검증|없는 인용/불일치 차단. 실제 인용된 제목·유형·본문·URL·수집일 표시. 전 문장 의미 검증은 아님.|
|F2009|항목 선택·대화 분리|구현·일부 화면 검증|회사/분기별 session 대화. 위젯과 영속 선택값 분리로 메뉴 왕복 조건 유지.|
|F2010|금융 특화 검토 지원|구현·제한적 검증|공시·업계 사례·검토 제안 구분, 익명 회사 귀속 금지, 분류축 합산 금지.|
|F2011|자연어 조건 탐색|구현·일부 검증|연도/분기/최소건수/업권 데이터 필터 + 의미 후보 검색 + 질문 항목 이동.|
|F2012|진행·예외 안내|구현·일부 검증|키/색인/데이터/네트워크/JSON 오류 안내. AI 범위 밖과 근거 없는 기간 보류.|
|F2013|프론트 분리|미선택|Streamlit/CSS 사용.|
|F2014|MMR|구현·실제 비교|실제 ONNX/DB로 유사도/MMR 순서 차이 확인.|
|F2015|RAG 전후 비교|실제 실행·독립 평가 미완료|대표7문항 실제 응답과 이전 실패 기록. 개발자 선정 스모크이며 일반 정확도 아님.|
|F2016|다중 출처|일부 구현|공시와 금감원 사례 결합. 임의 출처 추가 없음.|
|NF2001|응답 시간|실측·기준 보장 아님|대표 질문별 실제 시간 기록. 최초 색인/호출 오류/재시도에 따라 변동.|
|NF2002|영속 캐시|구현·로컬 검증|검색어/선별 SQLite + 본문 SHA256 캐시 + DB 실제 존재 확인 후 완료 기록.|
|NF2003|키 관리|구현·패키지 검사|현재 프로젝트 .env만 사용. Git·ZIP 제외.|
|NF2004|내부 정보 비노출|구현·일부 검증|안전한 오류 메시지, 원문 HTML 이스케이프, 프롬프트/키/traceback UI 비노출.|
|NF2005|모듈 분리|구현|collection/preprocessing/analysis/rag/ui/scripts/tests.|
|NF2006|외부 API 예절|구현·캐시 검증|공식 허용 호스트·robots·간격·timeout·Retry-After. 기존 출처 캐시 사용, 최신 재수집 성공과 구분.|
|NF2007|출처·이용 조건|부분 확인|공식 출처·수집일 유지. 원문 재배포 허락 미확인으로 ZIP에서 원문/본문 제외.|

회사·분기 항목 177개로 약100개 수량 조건을 충족한다. 공식 셀프·상호 평가와 독립 품질 평가는 미반영이다.
