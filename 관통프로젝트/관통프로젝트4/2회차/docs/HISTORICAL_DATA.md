# FinVOC Korea — 과거 공시 확장

2026-10-23. 이전에는 2026Q1·Q2 중심37개 항목을 모았고 파서도 해당 기간만 허용했다.
공식 검색에 과거 자료가 없었던 것이 아니다. 기존 수집 범위와 코드가 제한적이었다.

## 현재 실제 범위

- 손해보험협회 공식 연도/분기 선택으로 2024Q2·2024Q4·2025Q2·2025Q4 표를 수집했다.
- 각 페이지의 전분기/당분기 본문을 확인해 2024Q1~2025Q4를 추가했다.
- 기존2026Q1·Q2와 합쳐 회사·분기177개, 공시 명의21개사, 통계 관측값2,303개다.
- 원문 회사명·분기·분류축·원문 행·URL·수집일을 보존한다. 분류축 행 수를 항목 수로 부풀리지 않는다.
- 현재 공통2026Q2는18개사다. 과거에만 있는 MG/캐롯/코리안리를 현재 회사로 채우지 않는다.
- 교보생명은2026Q1·Q2만 확보했다. 손해보험 자료를 생명보험에 복사하지 않는다.

## 공식 조회 경로

[손해보험협회 과거2025Q4 표](https://consumer.knia.or.kr/m/disclosure/item/01.do?01_searchYear=2025&01_seasrchQuarter=4)

HTML의 실제 선택 필드 이름을 확인해 GET으로 공개 표를 조회했다. 선택된 옵션뿐 아니라 본문의 대상기간도 검사한다.
요청 분기와 다른 최신 표를 반환하면 저장을 중단한다. robots·타임아웃·간격·재시도·영속 캐시는 기존 수집기를 사용한다.
수집 원문/키/가상환경을 제출 ZIP에 넣지 않는다. 새 컴퓨터는 prepare_data.ps1로 준비해야 하며 원격 양식 변경 시 실패할 수 있다.

## 데이터 검사와 보류

기존483개 관측값 파일은 변경하지 않고 `insurer_stats_history.json`에 확장본을 만들었다.
부분합/세 분류축 합계/고유키/건수 결측/음수를 검사하고 기존과 겹치는 하나2025Q4의13개 관측값도 대조했다.
같은 URL을 반복 조회할 때 실제 파일/해시 캐시4회 적중, HTTP0회를 확인했다.

제외한 항목:

|회사·기간|사유|
|---|---|
|AIG2024Q3·2024Q4|원문 일부 건수 결측. 0으로 채우지 않고 회사·분기 전체 보류|
|AIG2025Q1|접수경로/유형36건, 상품39건으로 불일치. 임의 수정 없이 전체 보류|

이는 공식 원문의 현재 조회본과 파서 결과에서 발견한 불일치다. 회사 전체 공시의 진위나 다른 버전을 판정한 것은 아니다.
향후 정정 공시/회사 직접 공시로 확인하기 전까지 미확인으로 유지한다.

## 비교 기준

협회 페이지는 **2024년2분기부터 공시기준 개선**을 안내한다. 해당 경계의 전분기 증감은 계산하지 않는다.
추이 차트는 기준 전후를 다른 선으로 나누며 누락 분기는 None으로 남겨 선을 잇지 않는다.
상품 상세 분모가 없는 과거 협회 표는 회사의 최신 공시에서 설명한 분모를 과거에도 확인한 것처럼 표시하지 않는다.
MG와 예별, 캐롯과 한화는 계약/회사 이력을 검증하지 않은 채 자동 병합하지 않는다. 코리안리는 재보험 업권으로 구분한다.

## 직접 다시 준비

```powershell
.\.venv\Scripts\python.exe -m src.collection.collect_history
.\.venv\Scripts\python.exe scripts\index_rag.py
.\.venv\Scripts\python.exe -m pytest -q
```

화면과 RAG 모두 과거 확장본이 있으면 우선 사용하고 없으면 기존483행 자료로 동작한다.
기존 집계/사례 파일을 삭제하지 않았다. 실제 수집·제외·검사 기록은 [insurer_history.json](../reports/insurer_history.json)을 확인한다.
