# 화면·내용 자체 검토와 개선 기록

개편일: 2026-10-22. 사용자 제공 업무용 대시보드 사진의 정돈된 메뉴, 낮은 채도의 색,
균일한 정보 카드, 명확한 필터 구조를 참고했다. 실제 FinVOC 브라우저 화면을 확인해 수정했다.
이 기록은 개발 중 자체 점검이며 외부 사용자 평가나 AI 정확도 평가가 아니다.

## 발견한 문제와 반영한 수정

| 문제 | 사용자에게 생기는 불편 | 반영한 수정 |
|---|---|---|
| 첫 화면이 파일 수·검사 건수 중심 | 서비스가 어떤 업무에 쓰이는지 바로 이해하기 어려움 | 선택 회사·분기의 민원 수, 변화, 주요 유형, 접수경로를 첫 화면에 표시 |
| 넓은 사이드바와 큰 제목 | 본문 공간을 많이 쓰고 차트가 첫 화면에 없음 | 상단 4개 탐색 메뉴, 간결한 브랜드 바, 제목 크기·간격 조정 |
| 긴 숫자 카드 보조 문구가 잘림 | 비교 기간·검사 설명이 끝까지 보이지 않음 | 카드에는 짧은 업무 수치만 두고 긴 설명은 도움말/자료 관리에 배치 |
| 차트 스타일과 정보 우선순위가 약함 | 핵심 민원과 접수경로를 빠르게 파악하기 어려움 | 남색·청록 팔레트, 흰 카드, 같은 높이의 막대/도넛 차트, 건수 내림차순 정렬 |
| 분석 화면과 사례 검색이 분리됨 | 어떤 질문을 넣어야 할지 사용자가 다시 생각해야 함 | 주요 유형마다 검토 질문과 실제 검색으로 이동하는 버튼 추가 |
| 결과에 긴 원문을 모두 나열 | 후보 비교·선택·근거 읽기가 어려움 | 왼쪽 후보 목록, 오른쪽 선택 사례의 쟁점/처리결과/민원내용/유의사항 |
| 긴 원문이 고정폭 텍스트처럼 보임 | 작은 폭에서 긴 줄을 읽기 불편함 | 문장 줄바꿈, 원문 카드, 13px 본문과 넉넉한 줄 간격, 원문 링크를 상세 상단에 배치 |
| 문자 검색 결과가 확정 답처럼 읽힐 수 있음 | 실제 의미 검색/생성/보상 판정으로 오해할 위험 | ‘검색 후보’, ‘원문 검색’으로 표시하고 문자열 점수는 별도 설명으로 이동 |
| 개발 진행 상황·경고가 본문을 압도함 | 중요한 업무 수치보다 개발 설명이 눈에 먼저 들어옴 | 검증·이용 조건은 자료 관리로 이동하되 회사와 사례의 연결 제한/생성 전 상태는 짧게 유지 |
| 캐시가 파일 변경을 자동 반영하지 않음 | 데이터 준비 후 이전 값이 남을 수 있음 | 데이터 파일 수정 시각을 캐시 키에 포함 |

## 유지한 내용 원칙

- 숫자는 실제 정제 공시에서만 계산한다. 화면을 채우기 위한 가상의 추이·실시간 상태·우선순위 점수를 만들지 않았다.
- 유형별 우선 표시는 선택 회사 내부의 공시 건수 순이다. 소비자 피해 강도나 회사 우열의 순위가 아니다.
- 보상 유형 구성비를 보험금 부지급률로 바꾸지 않았다.
- 검토 질문은 담당자가 확인할 주제다. 해당 회사에서 반복 확인된 원인이나 AI 개선 전략으로 표시하지 않았다.
- 익명 업계 사례를 선택 회사의 사건으로 귀속하지 않는다.
- 원문 검색은 문자 기준선이고 생성형 AI 답변이 아니다. 의미 검색·GMS 연결 상태를 꾸미지 않았다.
- 정식 조정결정서 전문, 독립 성능평가, 공개 재배포 허락이 확보됐다는 표현을 추가하지 않았다.

## 파일 구조

`app.py`는 화면 진입점이며 스타일은 `src/ui/theme.css`, 공통 카드/차트는
`src/ui/components.py`, 화면별 배치는 `src/ui/views.py`, 수치 계산은 `src/analysis/dashboard.py`로 나눴다.
초보자 설명은 `CODE_WALKTHROUGH.md`에 갱신했다.

## 검증 범위

자동 검사는 실제 로컬 데이터로 메뉴 이동, 보험사·기간 변경과 필터 유지,
공시 수치·전분기 변화, 상품별 결측 환산건수, 금감원 전년 동기 비교,
검토 카드→실제 검색, 예시 검색, 후보 선택, 결과 없음, 원문 HTML 이스케이프를 확인한다.
자동 검사 중 외부 HTTP/GMS 요청은 차단한다.

브라우저에서 초기 화면의 카드/차트/메뉴, 주요 유형 카드, 관련 사례 이동과
후보/상세 배치를 직접 확인했다. 화면 증거와 최신 결과는
`reports/evidence/design/`, `reports/design_validation.json`, `reports/pytest-design.xml`에 보관한다.
원문이 보이는 화면 증거는 로컬에만 두며 소스 ZIP에 포함하지 않는다.
실제 모바일 기기·여러 브라우저·외부 사용자 사용성 검사는 아직 수행 전이다.

기존 자료는 수정하지 않았으며 개편 전 소스/화면을 `runtime/design_before_20261022/`와
`reports/evidence/design/before.png`에 보존했다. 최신 자동 검사와 원본 불변 검사는 별도 결과 JSON에 기록한다.
