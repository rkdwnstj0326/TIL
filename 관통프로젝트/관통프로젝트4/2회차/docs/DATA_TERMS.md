## 금감원 정책의 적용

[공식 저작권 정책](https://www.fss.or.kr/fss/main/contents.do?menuNo=200701)은 원칙적인 무단 복제·배포 금지와
교육·연구 등 정당한 범위의 인용, 비영리 개인 이용을 구분한다. 수익 또는 그에 상응하는 혜택을 위한 이용,
다른 인터넷 사이트 게시와 직접 링크에 관한 별도 협의/표시/통지 조건도 안내한다.
따라서 현재 로컬 교육·연구 검토를 진행하되, 취업용 공개 웹사이트·공개 저장소의 원문 재배포가
자동으로 허용된다고 판정하지 않는다. 제3자 권리 자료도 있을 수 있다.

이 프로젝트는 권리자에게 연락하거나 허락을 받았다고 기록하지 않았다. 사용자의 승인 없이 이메일도 보내지 않았다.
공개 전에는 실제 게시 내용과 인용 범위를 정한 뒤 필요한 조건을 확인해야 한다.

## 수집기 동작

- UA: `FinVOCKoreaResearch/0.1`. 다른 수집기·일반 브라우저를 사칭하지 않는다.
- 허용 목록에 등록한 공식 호스트만 사용한다. 다른 호스트로의 리다이렉트는 따라가지 않는다.
- robots를 확인하고 차단 경로는 중단한다. 403 접근 제한을 재시도하여 우회하지 않는다.
- 호스트별 호출 간격, 연결/읽기 타임아웃, 429/5xx 최대 3회 시도, Retry-After 초/HTTP-date 처리가 있다.
- 긴 Retry-After는 자동으로 대량 재요청하지 않고 중단한다.
- URL별 영속 캐시에 URL·수집 시각·크기·SHA-256·콘텐츠 유형을 기록한다.
- 재사용 전 실제 파일과 SHA-256을 검사한다. 캐시가 손상되면 원본을 무단 덮어쓰지 않는다.
- robots는 실행 당시 저장한 스냅샷이다. 장기간 후 새로 수집하기 전에는 변경 여부를 다시 확인해야 한다.

## 개인정보와 재배포 경계

현재 입력은 기관이 이미 공개한 사례 설명이다. 고객 민원 접수 원장이나 개인 금융거래 내역을 수집하지 않았다.
70개 본문에 전화번호·이메일·주민등록번호 유사 정규식을 적용한 결과 해당 패턴은 발견되지 않았다.
이는 실명·간접 식별정보·건강정보가 없다는 보증이 아니다. 본문에 질병/사고 상황 등이 있으므로
외부 공개 전에는 개별 내용을 사람이 검토해야 한다.

- `data/raw/`: 수집 원문. Git/개발 ZIP 제외
- `data/private/`: 추출 본문과 사례 구조화 결과. Git/개발 ZIP 제외
- `data/processed/`: 출처 행을 포함한 정제 통계. 공개 재배포 검토 전 Git/개발 ZIP 제외
- `reports/evidence/`: 로컬 원문 대조용 PDF 이미지. Git/개발 ZIP 제외
- `.env`: 사용자 비밀값 저장 전용. Git/ZIP/로그 제외

코드/재현 스크립트와 원문의 공개 권리를 혼동하지 않는다. 원문이 없는 개발 ZIP은 준비 스크립트로
접근 정책을 확인하여 자료를 다시 확보하는 방식이다. 출처 개편·정책 변경 시 재수집 가능성을 보장하지 않는다.

## 2026-10-22 보험사 확장

손해보험협회 소비자포털 통합 민원 공시, 연결된 공식 작성 매뉴얼(HWP), 교보생명 직접 공시를
추가했다. 협회 robots 경로는 JPEG 오류 이미지로 이동하여 유효한 정책 텍스트가 없었음을 기록했다.
정상 공개 HTML/연결 매뉴얼만 저속 수집·캐시했으며 금지 규칙이나 접근 차단을 우회하지 않았다.
이를 명시적 수집 허용 정책으로 해석하지 않는다. 교보생명 robots는 공개 경로를 금지하지 않았다.

원문은 공개 조회 자료이지만 자유 재배포 라이선스는 확인되지 않았다. 현재도 로컬 개인 교육·연구
범위이며 Git·소스 ZIP에 새 원문과 가공 데이터를 포함하지 않는다. 권리자에게 허가를 받았다고
기록하지 않는다. HWP는 OLE 본문 텍스트 레코드만 읽고 포함 스크립트/매크로를 실행하지 않는다.
공식 통합 표의 실제 분기와 원문 수치로만 추가하며 검색엔진 요약은 수치 원본으로 사용하지 않는다.

분모·제외조건 검토의 구체적인 확인 결과와 보류 항목은 `reports/INSURER_EXPANSION.md`에 있다.
