# FinVOC Korea — 제출 점검

코드·문서·검증 결과는 2회차 안에 직접 관리한다. `제출용 압축.cmd`를 제출 직전에 실행한다.

필수 제출 문서: README, 요구사항 정의/대조, RAG 설계, 테스트/화면 증거, 출처·이용조건, 공식 셀프·상호 결과.
회사·분기 수량 조건은 충족했다. 공식 평가와 독립 품질 평가가 남아 최종 충족으로 표시하지 않는다.

ZIP은 선생님 지정 파일명으로 dist 안에 생성한다. 실제 .env·가상환경·원문·정제 데이터·로컬 DB·모델 캐시는 제외한다. 재현 시 README의 자료 준비 절차가 필요하며 원격 사이트 변경 시 실패할 수 있다.
