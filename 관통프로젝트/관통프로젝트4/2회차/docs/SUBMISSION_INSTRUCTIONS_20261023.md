# FinVOC — 선생님의 최신 제출 안내 반영

기준일: 2026-10-23. 사용자가 전달한 최신 안내를 파일명과 업로드 위치의 기준으로 사용한다.
과제 PDF의 기능·문서 요구사항은 유지하며, 파일명/제출 위치는 이번 안내를 우선한다.

1. 형식: `AI_코어프로젝트2_주제명_지역_반_성명.zip`
2. FinVOC 파일명: **`AI_코어프로젝트2_FinVOC금융민원분석AI_서울_1반_강준서.zip`**
3. [선생님이 공유한 제출 링크](https://abit.ly/0i3bjzz)의 **2회차** 폴더에 업로드한다.
   브라우저로 확인한 경로는 AI_Core_프로젝트 → 2회차이며,
   [확인된 2회차 폴더](https://drive.google.com/drive/folders/1KiPj_LXw36zPfkYDm4WNh2SBBzUXZU1R)다.
4. 가상환경은 압축하지 않는다. 현재 패키지는 `.venv`, `venv`, `env`, `site-packages`, `pyvenv.cfg` 등
   가상환경 흔적을 검사하고, 실제 `.env`·키·연락처·모델 캐시·DB·원문/정제 데이터도 제외한다.

이전 파일명·기존 제출처를 적은 과거 ZIP은 이력 보존용이다. 실제 업로드할 파일은 위 이름의 최신 ZIP이다.
ZIP의 내용 완료 여부는 `SUBMISSION_STATUS.json`과 대조표로 확인한다. 새 이름으로 압축한 것과 필수 RAG 구현 완료는 다르다.
공식 셀프·상호 결과는 아직 반영되지 않았다. 이 안내를 반영하는 과정에서 실제 업로드는 진행하지 않았다.
