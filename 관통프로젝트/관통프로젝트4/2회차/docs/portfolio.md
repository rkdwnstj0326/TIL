# FinVOC Korea — 포트폴리오 설명

공식 보험 공시의 분기·분모·분류 기준을 보존하면서 익명 분쟁 사례를 근거로 검토하는 개인 프로젝트입니다.
자료 수집/정제, 공시 검증, 한국어 임베딩과 Chroma 검색, LangGraph/GMS 근거 생성, Streamlit 화면을 연결했습니다.

설명할 실제 기술 문제:

- 한국어 문장이 모델128토큰 제한으로 잘리는 문제: 토큰 오프셋 창 분할과 전체 구간 포함 검사.
- 같은 업계 문서를 여러 항목에 쓸 때 덮어쓰는 문제: 항목ID·문서ID·순번 키와 DB 필터.
- 공시 분류축을 합산하는 해석 오류: 축별 구조와 생성 지침 유지.
- 메뉴 이동 후 회사·분기 초기화: 화면 위젯과 영속 선택값 분리, 회귀 검사.
- 미래 기간 질문에 현재 수치를 답한 실제 모델 오류: 기간 검사로 결과 거부/보류, 실패 기록 보존.

실제 증거는 테스트 보고서와 GMS 대표7문항 비교입니다. 수치 검사 통과를 일반 AI 정확도로 표현하지 않습니다.
민원 감소율, 회사 우열, 실무 도입 성과, 완료하지 않은 공식 평가를 만들어 쓰지 않습니다.
회사·분기177개 항목을 확보했습니다. 남은 과제: 독립 검색 정답셋과 답변 전문가 평가, 공식 셀프·상호 평가.
