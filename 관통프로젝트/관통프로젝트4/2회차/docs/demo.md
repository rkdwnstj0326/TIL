# FinVOC Korea — 시연 순서

1. FinVOC 실행.cmd 더블클릭. 회사·분기 선택 후 실제 공시 수치 확인.
2. 민원 분석에서 분류축과 분모 안내 확인. 사례 탐색으로 이동 후 다시 돌아와 선택 유지 확인.
3. 근거 기반 AI에서 메타데이터 색인 준비·확인 클릭.
4. 2026년 2분기 민원 합계·전분기 대비 질문 후 인용번호의 실제 출처 펼치기.
5. 청구 추가 서류 사례 질문. 업계 사례를 특정 회사 사건으로 연결하지 않음을 설명.
6. 미래 기간 질문에서 확인 불가 보류 확인.
7. 회사·분기를 바꿔 대화 분리 확인. 조건으로 공시 찾기에서 2026년2분기100건이상 검색 후 항목 선택.
8. 자료 관리에서 출처·수집일·미확인 분모 확인. README에서 실제 검증과 남은 항목 설명.
9. FinVOC 종료.cmd로 서버 종료. 제출용 압축.cmd로 ZIP 재생성.

대표7문항은 실제 GMS로 실행했지만 일반 정답률이 아닙니다. 177개 항목의 수량 조건은 충족했습니다. 독립 품질 평가·공식 셀프/상호 결과는 남아 있습니다.
