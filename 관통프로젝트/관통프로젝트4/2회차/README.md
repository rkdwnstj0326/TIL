# FinVOC Korea — 금융민원 분석 및 근거 기반 AI

**서울 1반 강준서 · AI 코어프로젝트 2 · 2026-10-23**

보험 공시의 반복 민원 유형을 확인하고, 금융감독원 공개 사례의 원문을 검색해 검토 방향을 정리하는 워크벤치입니다.
공시 통계와 익명 업계 사례를 구분하며, 사례를 선택 보험사의 실제 사건으로 추정하지 않습니다.

현재 실제 다국어 의미 검색·ChromaDB·LangGraph·GMS 생성이 연결되어 있습니다.
현재 회사·분기 항목177개로 약100개 수량 조건을 충족합니다. 공식 셀프·상호 평가와 독립 품질 평가는 미반영입니다.
전체 제출 조건을 모두 충족한 완료본이라고 표시하지 않습니다.

## 1. 코드 위치와 구성

이 컴퓨터에서는 **바탕화면 ai_core_pjt/2회차** 폴더가 실제 개발·실행 위치입니다.
중간 제출준비 폴더는 사용하지 않습니다.

|파일·폴더|역할|
|---|---|
|app.py|Streamlit 앱의 시작점과 메뉴|
|src/ui/|화면 배치·디자인·근거 기반 AI 대화|
|src/collection/|공식 통계·공시·사례 수집과 요청 캐시|
|src/preprocessing/|HTML/PDF/HWP 본문·통계 정제|
|src/analysis/|집계·증감 계산·문자 검색 기준선|

## 2. 이 컴퓨터에서 켜고 끄기

1. `FinVOC 실행.cmd`를 더블클릭합니다.
2. 열린 브라우저에서 사용합니다. 기본 주소: http://127.0.0.1:8540/
3. 종료할 때는 `FinVOC 종료.cmd`를 더블클릭합니다.

브라우저 탭만 닫으면 서버는 계속 실행됩니다. 실행 파일을 다시 누르면 이 앱 서버를 재사용합니다.
포트가 사용 중이면 다른 빈 포트를 선택하며 다른 프로세스를 종료하지 않습니다.
`127.0.0.1`은 현재 컴퓨터 주소이므로 다른 사람에게 보내는 공개 주소가 아닙니다.

## 3. 처음 받은 컴퓨터에서 설치

Windows PowerShell에서 압축을 푼 프로젝트 폴더로 이동한 뒤 실행합니다. Python 3.12가 필요합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\prepare_data.ps1
.\.venv\Scripts\python.exe scripts\index_rag.py
```

`setup.ps1`은 프로젝트 안에 .venv를 만들고 requirements.txt의 버전을 설치합니다.
`prepare_data.ps1`은 공식 사이트에서 자료를 수집하고 정제·검증합니다. 인터넷이 필요합니다.
robots/접근 제한은 우회하지 않습니다. 사이트 양식이나 정책이 바뀌면 준비가 중단될 수 있습니다.
첫 의미 모델 실행 때 공개 다국어 MiniLM ONNX 파일을 내려받습니다.
Windows의 모델·Chroma·검색 캐시는 사용자 LOCALAPPDATA/FinVOCKorea에 보관합니다.

`.env.example`을 복사해 `.env`를 만들고 `GMS_KEY=` 뒤에 본인 키를 직접 저장합니다.
이미 .env가 있으면 덮어쓰지 말고 필요한 값만 수정하세요. 키를 채팅·Git·문서에 넣지 않습니다.
개인 OpenAI 키 발급이나 Codex 인증 변경은 필요 없습니다.
키가 없으면 실제 의미 검색 원문 발췌만 제공하며 생성 답변으로 표시하지 않습니다.

터미널에서 직접 실행하고 종료하려면:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address=127.0.0.1 --server.port=8540
# 위 터미널에서 Ctrl+C를 눌러 종료합니다.
```

## 4. 사용 순서

1. **업무 개요**: 보험사·분기를 선택하고 민원 건수와 유형별 분포를 확인합니다.
2. **민원 분석**: 같은 기간과 분류축에서 수치·직전 분기 변화·분모를 검토합니다.
3. **사례 탐색**: 문자 검색 기준선으로 관련 업계 사례의 원문을 직접 읽습니다.
4. **근거 기반 AI**: `메타데이터 색인 준비·확인`을 누른 뒤 질문합니다.
5. 답변의 [1] 같은 인용 번호에 대응하는 출처를 펼쳐 제목·유형·원문·수집일·URL을 확인합니다.
6. 회사·분기를 바꾸면 해당 항목의 대화가 별도로 표시됩니다.
7. **조건으로 공시 찾기**에서 `2026년 2분기 민원 100건 이상인 손해보험`처럼 입력해 후보를 찾고 질문 항목으로 선택할 수 있습니다.
8. **자료 관리**에서 출처와 집계 기준을 확인합니다.

시연 질문:

- 2026년 2분기 민원 합계와 직전 분기 대비 증감을 알려줘.
- 보험금 청구 시 진료비 영수증 외 추가 서류를 요구한 업계 사례에서는 무엇을 확인했어?
- 익명 백내장 사례를 선택 보험사의 사건이라고 확정할 수 있어?
- 하나손해보험의 2030년 2분기 민원 합계는 몇 건이야?

## 5. 실제 데이터와 해석 한계

- 과거 공시 포함21개사(손보19·생보1·재보험1), 회사·분기177개, 회사 통계2,303행·권역28행.
- 손해보험 과거 자료를 2024년1분기~2026년2분기로 확장했습니다. 현재 공통2026Q2 자료는 기존18개사입니다.
- MG·예별·캐롯 등 원문 회사명을 자동 병합하지 않습니다. 교보생명은 아직2026년1·2분기만 있습니다.
- 2024Q2 공시기준 개선 전후의 증감은 보류하고 추이 선도 연결하지 않습니다. AIG의 결측2분기·합계불일치1분기는 제외했습니다.
- 수집 방법과 제외 사유: [과거 공시 확장](docs/HISTORICAL_DATA.md).
- 금감원 공개 사례70개 게시 문서, 고유 제목69개. 실제 민원 모집단의 빈도가 아닙니다.
- 서로 다른 분류축을 더하지 않습니다. 상세 상품 분모가 미확인인 회사의 환산값 비교는 보류합니다.
- 사례의 회사명·별도 결정일·분리된 당사자 주장은 공개된 경우에만 취급합니다.
- 사례 검색 후보 범위는 현재 확보한 공식 목록입니다. 웹 전체 최신 검색이 아닙니다.
- 개별 사건의 지급/법적 결과를 확정하거나 전문가 판단을 대신하지 않습니다.
- 출처: [공식 자료·이용 범위](docs/sources.md), [상세 이용 조건](docs/DATA_TERMS.md).

## 6. 실제 RAG 흐름과 검사

메타데이터 미리 색인 → 질문 검색어 추출 → 공식 목록 후보/GMS 선별 → 질문 시점 본문 fetch/색인
→ item_id 필터 의미 검색/MMR → 선택 메타데이터 병합 → GMS 생성 → 인용 검사.
LangGraph 실행 노드는 retrieve와 generate 두 개입니다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\verify_rag_local.py
# 아래는 실제 GMS 사용량을 소모합니다. 자동 시험과 분리했습니다.
.\.venv\Scripts\python.exe scripts\gms_check.py --run
.\.venv\Scripts\python.exe scripts\validate_gms_rag.py --run
```

실제 검증 중 미래 기간 질문에 현재 수치를 답하는 모델 오류를 발견했습니다.
기간 검사로 잘못된 답변을 보류하며 이 실패와 재시도도 기록했습니다.
대표7문항 결과는 일반 정확도나 금융/법률 판단 품질을 입증하지 않습니다.
[실제 테스트 결과](docs/test_results.md), [RAG 전후 비교](docs/rag_comparison.md)를 확인하세요.

## 7. 제출 직전에 압축

`제출용 압축.cmd`를 더블클릭합니다. 코드·문서·검증 결과를 선택해 아래 파일을 만듭니다.

`dist/AI_코어프로젝트2_FinVOC금융민원분석AI_서울_1반_강준서.zip`

폴더 전체를 탐색기로 바로 압축하면 .env나 가상환경까지 포함될 수 있으므로 전용 도구를 사용하세요.
실제 .env·키·연락처·가상환경·DB·모델 캐시·runtime·원문/정제 데이터는 제외합니다.
기존 ZIP은 runtime에 보관한 후 갱신하며 CRC·해시·문서 링크·제외 여부를 검사합니다.
다른 컴퓨터에서는 위의 설치·자료 준비 단계가 필요합니다.
선생님이 공유한 링크의 **2회차** 폴더에 제출합니다. 자동 업로드는 하지 않습니다.
