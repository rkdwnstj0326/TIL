# AI Python 실습 시작하는 법



## 1. 처음부터 한다면

1. AI python 폴더에서 vscode 실행

2. 가상환경 생성 

   ```bash
   python -m venv venv
   ```

3. 터미널에서 가상환경 활성화 

   ```bash
   source venv/Scripts/activate
   ```

4. 패키지 설치

   ```bash
   pip install -r Day01/requirements.txt
   pip install -r Day02/requirements.txt
   ```

5. 쥬피터 랩 활성화

   ```bash
   jupyter lab
   ```

6. 쥬피터 랩 종료

   - 터미널에서 `ctrl` + `c`
