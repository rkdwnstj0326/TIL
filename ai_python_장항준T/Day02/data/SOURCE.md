# 타이타닉 실습 데이터 출처

## 출처

| 항목 | 내용 |
| --- | --- |
| 파일명 | `titanic.csv` |
| 배포 위치 | Seaborn 예제 데이터 저장소 |
| 원본 URL | https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv |
| 원 데이터 안내 | https://www.kaggle.com/c/titanic/data |
| 데이터 크기 | 891행 × 15열 |
| 사용 범위 | 실습 3 EDA와 시각화, 전처리 |

## 이용 조건

Seaborn 예제 데이터 저장소는 문서 예제를 위한 다운로드 위치이며, 일반 데이터 아카이브 용도로는 사용하지 않도록 안내합니다. 저장소 README에는 Titanic의 원 데이터 위치로 Kaggle이 연결되어 있습니다. 이 사본은 교육장 오프라인 실습용으로만 사용하고, 외부 재배포 전에는 원 데이터의 최신 이용 조건을 확인하세요.

## 배포 목적

네트워크가 차단된 교육장에서도 실습을 계속할 수 있도록 원본 CSV의 로컬 사본을 함께 배포합니다. 노트북은 Seaborn, 원본 CSV URL, 이 로컬 파일 순서로 데이터를 불러옵니다.

## 출처 표기 예시

```text
데이터: seaborn-data의 Titanic 예제 데이터
원 데이터 안내: Kaggle Titanic competition data
```
