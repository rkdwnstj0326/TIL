# 2-1. 토큰화와 임베딩 — Easy 실습 가이드

## 실습 개요

이 실습은 **"사람의 문장이 어떻게 딥러닝 모델의 입력이 되는가"** 를 직접 구현하며 이해하는 과정이다.

```
"안녕하세요" → [토큰화] → ['안녕', '##하', '##세요'] → [정수 인코딩] → [11655, 2205, 3606]
  → [임베딩] → [[0.1, 0.4, ...], [0.9, 0.2, ...]]  ← 딥러닝 모델의 진짜 입력
```

> ⚠️ 위 정수 값은 **형태를 보여주기 위한 예시**이다.
> 실제 ID는 어떤 토크나이저를 쓰느냐에 따라 달라지므로, 노트북을 실행해 직접 확인하자.



---



## 사전 준비

### 환경 요구사항

- Python 3.12+
- GPU 사용 시: CUDA 지원 PyTorch 설치 필요 ([설치 가이드](https://pytorch.org/get-started/locally/))
- 인터넷 연결 (데이터셋 20MB, 사전학습 모델 약 450MB 다운로드)

### 패키지 설치

각 노트북 첫 셀에 `pip install` 코드가 포함되어 있으므로 별도 사전 설치는 불필요하다.



---



## 실습 구성 (4개 노트북)

> 2_0은 **교안(PPT) 수업 중** 함께 진행하고, 2_1 ~ 2_3은 **자기주도 실습**으로 진행한다.

### 📒 2_0_Practice.ipynb — 허깅페이스로 토큰화 & 임베딩 체험

> 교안 슬라이드 12~24와 함께 진행

이미 학습된 `klue/bert-base` 모델을 HuggingFace에서 불러와, 토큰화와 임베딩의 **전체 파이프라인을 빠르게 체험**한다. 원리보다는 "무엇이 일어나는가"에 집중한다.

- `AutoTokenizer`로 문장을 정수 ID로 변환
- `AutoModel`로 정수 ID를 768차원 의미 벡터로 변환
- 토크나이저와 모델의 **짝꿍 규칙** 확인
- **"임베딩"이라는 말의 두 가지 뜻** 구분 (입력 임베딩 vs 문맥 임베딩)



### 📒 2_1_Tokenization.ipynb — 토크나이저를 직접 학습시키기

> "단어 사전은 어떻게 만들어지는가?"

2_0에서는 이미 만들어진 토크나이저를 **사용**만 했다. 여기서는 원리를 파헤친다.

1. **네이버 영화 리뷰(NSMC) 데이터** 다운로드 및 정제
2. WordPiece 알고리즘으로 **토크나이저를 직접 학습** (30,000개 단어 사전 구축)
3. 학습 결과를 `nsmc-vocab.txt` 로 **저장** → 2_2, 2_3에서 재사용
4. 학습된 토크나이저로 문장을 **토큰화 + 정수 인코딩**하여 결과 확인
5. 2_0과 달리 `[CLS]`/`[SEP]`이 붙지 않는 이유 확인



### 📒 2_2_Embedding.ipynb — 임베딩 층을 직접 만들기

> "숫자를 의미의 좌표로 바꾸는 원리"

토큰화로 얻은 정수 ID는 단순한 번호에 불과하다. 이것을 의미가 담긴 벡터로 바꾸는 과정을 직접 구현한다.

1. 원핫 인코딩의 한계 확인 (차원 폭발 + 의미 관계 표현 불가)
2. `nn.Embedding`으로 **임베딩 층 생성** — 현재는 무작위 가중치
3. 임베딩이 "계산"이 아니라 **"표에서 행 꺼내기(lookup)"** 임을 직접 확인
4. 코사인 유사도로 "영화"와 유사한 단어 검색 → **무작위이므로 의미 없는 결과** 확인



### 📒 2_3_Hugging_Face.ipynb — 사전학습 모델의 지식 이식

> "거인의 어깨에 올라타기" — 전이학습의 첫 번째 맛보기

무작위 임베딩 층에 이미 잘 학습된 모델의 지식을 이식한다.

1. `klue/bert-base` 사전학습 모델에서 **임베딩 가중치 추출**
2. 우리 단어 사전과 사전학습 모델의 단어 사전에서 **공통 단어를 찾아 벡터 복사**
3. 코사인 유사도 재실행 → **2_2의 무작위 결과와 비교**
4. 이식되지 못한 토큰을 확인하며 **"사전이 다르면 생기는 문제"** 체감



---



## 실습 흐름 요약

```
2_0  [수업 중]  이미 만들어진 도구로 전체 과정 체험
                  ↓ "이제 원리를 파헤쳐 보자"
2_1  [자기주도]  토크나이저를 직접 학습 → 단어 사전 구축 → 파일로 저장
                  ↓
2_2  [자기주도]  임베딩 층 직접 생성 → 무작위 벡터 → 유사도 검색 실패
                  ↓ "무작위라서 의미가 없다... 어떻게 해결하지?"
2_3  [자기주도]  사전학습 모델의 지식을 이식 → 유사도 검색 재시도
```



## 생성되는 파일

| 파일 | 만드는 곳 | 쓰는 곳 |
|---|---|---|
| `ratings.txt` | 2_1 (다운로드) | 2_1 |
| `nsmc.txt` | 2_1 (정제 결과) | 2_1, 2_2, 2_3 |
| `nsmc-vocab.txt` | 2_1 (토크나이저 저장) | 2_2, 2_3 |

> 💡 `nsmc-vocab.txt` 덕분에 2_2, 2_3에서 토크나이저를 **다시 학습하지 않아도 된다.**
> (파일이 없으면 자동으로 재학습하므로 실행 자체는 실패하지 않는다)





## 주의사항

- 2_1 → 2_2 → 2_3은 **순서대로** 진행해야 한다 (이전 노트북의 결과물을 다음에서 사용)
- 2_1에서 생성되는 `nsmc.txt`, `nsmc-vocab.txt` 가 2_2, 2_3에서 필요하므로 **같은 디렉토리**에서 실행할 것
- GPU가 없어도 실습 진행이 가능하다 (CPU에서 약간 느릴 수 있음)
- 토크나이저 학습 중 진행 막대가 멈춘 것처럼 보여도 정상이다. 20만 문장을 분석하는 중이다.



## 자주 만나는 오류

| 증상 | 원인 | 해결 |
|---|---|---|
| `FileNotFoundError: nsmc.txt` | 2_1을 실행하지 않았거나 다른 폴더에서 실행 | 같은 디렉토리에서 2_1부터 순서대로 |
| `TypeError: ... NoneType` | 사전에 없는 단어를 `token_to_id()`에 넣음 | 다른 단어로 시도 |
| `IndexError` (Embedding) | 토큰 ID가 임베딩 표 크기를 초과 | `tokenizer.get_vocab_size()` 기준으로 생성 |
| `ModuleNotFoundError: torch` | 노트북 첫 셀을 건너뜀 | 첫 셀의 `pip install` 실행 |
| 모델 다운로드가 느림 | 최초 1회 다운로드 (약 450MB) | 이후에는 캐시를 사용하므로 빠르다 |



## 한 걸음 더

실습을 끝낸 뒤 아래를 직접 시도해 보면 이해가 훨씬 깊어진다.

- **다른 말뭉치로 토크나이저 학습하기** — 뉴스나 위키 텍스트로 학습하면 단어 사전이 어떻게 달라지는가?
- **`vocab_size` 바꿔 보기** — 5,000 / 30,000 / 50,000으로 학습했을 때 같은 문장의 토큰 수 비교
- **`min_frequency` 바꿔 보기** — 1로 두면 오타까지 사전에 들어온다. 확인해 보자.
- **다른 사전학습 모델 써 보기** — `beomi/kcbert-base`는 댓글 데이터로 학습되어 구어체에 강하다. 이식률이 어떻게 달라지는가?
